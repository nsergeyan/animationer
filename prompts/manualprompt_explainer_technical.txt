45. LOCATION-DRIVEN VISUALIZATION

When the narration is difficult to visualize literally, use the generated
location to create a physical visual metaphor or evidence environment.

Examples:

Narration about a missing recording:

belong.

Narration about contradictory evidence:

place the reference character in an evidence room with photographs, physical
objects, diagrams, and mismatched archival materials arranged on a worktable.

Narration about a strange scientific claim:

place the reference character in an experimental workshop beside physical
apparatus representing the claim.

Narration about a ridiculous conspiracy:

place the reference character in a cramped evidence workshop surrounded by
physically plausible but increasingly suspicious objects.

The location should help make an abstract narration concrete.
